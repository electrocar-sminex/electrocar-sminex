# Sminex — лендинг персональной зарядной станции

Готовый статический сайт для бесплатной публикации на GitHub Pages.

## Что находится в папке

- `index.html` — главная страница сайта.
- `assets/` — изображения и логотип в оптимизированных форматах WebP и SVG.
- `.nojekyll` — отключает лишнюю обработку GitHub Pages.

## Как опубликовать сайт бесплатно

1. Войдите на https://github.com/ и нажмите **New repository**.
2. Назовите репозиторий, например `sminex-landing`.
3. Выберите **Public** и нажмите **Create repository**.
4. Загрузите в репозиторий файл `index.html` и папку `assets` целиком (можно также загрузить `.nojekyll`).
5. Откройте в репозитории **Settings → Pages**.
6. В разделе **Build and deployment** выберите:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/ (root)`
7. Нажмите **Save** и подождите завершения публикации.
8. Адрес сайта появится в разделе **Settings → Pages**.

Важно: загружайте `index.html` и папку `assets` в корень репозитория, не внутрь дополнительной папки. Не переименовывайте `assets`, иначе изображения не найдутся.

## Локальная проверка

Откройте `index.html` в браузере. Для проверки на локальном компьютере этого достаточно.

## Примечание

Форма/ссылки обращения ведут на исходный сервис Sminex. GitHub Pages размещает только статические файлы и сам по себе не обрабатывает отправку форм или серверные запросы.
